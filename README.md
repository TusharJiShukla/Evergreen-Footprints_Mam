## 🌟 Overview
Welcome to the **Evergreen-Footprints_Mam** repository! This robust web application is built with PHP and focuses on providing users with detailed insights into their environmental impact by tracking emissions from various transportation modes.

## ✨ Features
- **Secure Authentication**: Robust user registration and login systems (`signup.php`, `login.php`).
- **Detailed Carbon Analysis**: Compute emissions specific to your mode of transit:
  - 🚗 Cars (`car.php`)
  - 🏍️ Motorbikes (`motorbike.php`)
  - ✈️ Flights (`flight.php`)
  - 🚌 Public Transit (`publictransit.php`)
- **Interactive Dashboards**: Engage with your data via `analyze.php` and manage your profile in `userinfo.php`.

## 🚀 Getting Started

### Prerequisites
- A local server environment like XAMPP, MAMP, or WAMP
- PHP 7.x or higher
- MySQL Database

### Installation
1. Clone the repository into your local server's root directory (e.g., `htdocs` for XAMPP):
   ```bash
   git clone https://github.com/yourusername/Evergreen-Footprints_Mam.git
   cd Evergreen-Footprints_Mam
   ```
2. Import the provided SQL database file (if available) via phpMyAdmin.
3. Configure your database connection settings in the `partials` directory.
4. Open your web browser and navigate to `http://localhost/Evergreen-Footprints_Mam/evergreenfootprints/welcome.php`.
